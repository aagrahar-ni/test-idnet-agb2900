agb2900 Instrument Driver Readme

To rate this instrument driver, go to the driver download page on the Instrument Driver Network.

1. Overview

Instrument Driver Technology: LabWindows/CVI Plug and Play
Manufacturer: Agilent
Supported Language(s): LabWindows/CVI, Measurement Studio for Visual Studio, Visual Studio
Supported Model(s): B2901A, B2902A, B2911A, B2912A, B2961A, B2962A, B2901B, B2911B, B2902B, B2912B, B2901BL, B2910BL, B2961B, B2962B
Model(s) Tested: B2912A, B2962A, B2912B , B2961B
Interface(s): USB, GPIB, Ethernet
Firmware Revision(s) Tested: 1.0.1121.1140,1.0.1231.944,5.0.2029.1911,5.0.2031.7499

Certified: Yes
NI Supported: Yes
Source Code Available: Yes

Driver Revision: 1.2
Original Release Date: 07/29/2011
Current Revision Date: 05/06/2021

2. Required Software

Some software components need to be installed before using this instrument driver.
The minimum versions of these components are listed below, and can be downloaded from the Download Site.

NI-VISA 4.0 or later

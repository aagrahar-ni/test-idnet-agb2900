agb2900_ConfigureSweep

ViStatus agb2900_ConfigureSweep (ViSession instrumentHandle, ViInt32 channel, ViInt32 outputMode, ViBoolean sweepEnabled, ViReal64 sweepStartValue, ViReal64 sweepStop, ViInt32 sweepStepCount, ViInt32 sweepMode, ViInt32 sweepDirection);

Purpose

Configures sweep for measurement and source. Output Mode control to select current or voltage mode to apply settings.

Parameters

Input
Name Type Description
instrumentHandle ViSession The ViSession handle that you obtain from the agb2900_Initialize function. The handle identifies a particular instrument session that can be passed to other functions.
Default Value:  None
channel ViInt32 Specified channel to perform action.
Valid Values:
AGB2900_INSTRUMENT_CHANNEL_1: Channel 1 (B2901BL, B2910BL, B2901B, B2911B, B2961B)
AGB2900_INSTRUMENT_CHANNEL_2: Channel 2 (B2902B, B2912B, B2962B)
Default Value:
AGB2900_INSTRUMENT_CHANNEL_1: Channel 1
outputMode ViInt32 Specified source output mode to apply settings.
Valid Values:
AGB2900_SOURCE_OUTPUT_MODE_CURRENT: Current List Sweep
AGB2900_SOURCE_OUTPUT_MODE_VOLTAGE: Voltage List Sweep
Default Value:
AGB2900_SOURCE_OUTPUT_MODE_VOLTAGE: Voltage
sweepEnabled ViBoolean Expected status of sweep function.
Valid Range:
VI_TRUE:  Enable. Output source is set to sweep.
VI_FALSE: Disable. Output source is set to constant current or voltage source.
Default Value:
VI_FALSE: Disable
sweepStartValue ViReal64 The start value of the sweep output.
Valid Range:
A valid voltage value or current value.
See help context for Output Level control in ConfigureSource function.
Default Value:
0.0 (V for voltage and A for current)
sweepStop ViReal64 The stop value of the sweep output.
Valid Range:
A valid voltage value or current value.
See help context for Output Level control in ConfigureSource function.
Default Value:
0.0 (V for voltage and A for current)
sweepStepCount ViInt32 The number of sweep steps for the specified channel. This setting is effective for both current sweep and voltage sweep.
Valid Range: (For Models B2910BL, B2901B, B2911B, B2961B, B2902B ,B2912B, B2962B, B2910CL, B2901C, B2911C, B2961C, B2902C ,B2912C, B2962C)
Min: 1
Max: 100000
Valid Range : (For B2901BL, B2901CL)
Min: 1
Max: 10000
Default Value:
1
sweepMode ViInt32 The scale mode and stair mode of the sweep output for the specified channel.
This setting is effective for both current sweep and voltage sweep.
Valid Values:
AGB2900_SWEEP_MODE_LINEAR_SINGLE: Linear Single. Select the linear scale and set the single sweep.
AGB2900_SWEEP_MODE_LINEAR_DOUBLE: Linear Double. Select the linear scale and set the double sweep.
Double sweep performs the sweep from start to stop to start.
AGB2900_SWEEP_MODE_LOG_SINGLE: Log Single Select the logarithmic scale and set the single sweep.
AGB2900_SWEEP_MODE_LOG_DOUBLE: Log Double. Select the logarithmic scale and set the double sweep.
Default Value:
AGB2900_SWEEP_MODE_LOG_DOUBLE: Linear Single
sweepDirection ViInt32 The sweep direction UP or DOWN for the specified channel.
Valid Values:
AGB2900_SWEEP_DIRECTION_UP: UP. Sets the sweep direction from start value to stop value.
AGB2900_SWEEP_DIRECTION_DOWN: DOWN. Sets the sweep direction from stop value to start value.
Default Value:
AGB2900_SWEEP_DIRECTION_UP: UP

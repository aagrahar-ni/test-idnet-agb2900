agb2900_ConfigureWaveformRamp

ViStatus agb2900_ConfigureWaveformRamp (ViSession instrumentHandle, ViInt32 channel, ViInt32 outputMode, ViReal64 riseTime, ViReal64 startLevel, ViReal64 endLevel, ViReal64 startTime, ViReal64 endTime);

Purpose

Configures current or voltage ramp waveform output.
Note:
This function is only supported by B296x family models B2961A/B2962A, B2961B/B2962B, and B2961C/B2962C.

Parameters

Input
Name Type Description
instrumentHandle ViSession The ViSession handle that you obtain from the agb2900_Initialize function. The handle identifies a particular instrument session that can be passed to other functions.
Default Value: None
channel ViInt32 Specified channel to perform action.
Valid Values:
AGB2900_INSTRUMENT_CHANNEL_1: Channel 1 (B2901BL, B2910BL, B2901B, B2911B, B2961B)
AGB2900_INSTRUMENT_CHANNEL_2: Channel 2 (B2902B, B2912B, B2962B)
Default Value:
AGB2900_INSTRUMENT_CHANNEL_1: Channel 1
outputMode ViInt32 Sets the source output mode of the specified channel.
Valid Values:
AGB2900_SOURCE_OUTPUT_MODE_CURRENT: Current. Sets the specified channel to the current source.
AGB2900_SOURCE_OUTPUT_MODE_VOLTAGE: Voltage. Sets the specified channel to the voltage source.
Default Value:
AGB2900_SOURCE_OUTPUT_MODE_VOLTAGE: Voltage
riseTime ViReal64 Sets the rise time of the current or voltage ramp waveform output.
Valid Range:
0 to 1000 seconds
Default Value:
0
startLevel ViReal64 Sets the start level of the current or voltage ramp waveform output.
Valid Range:
Voltage: -210V to 210V
Current: -3.03A to 3.03A
Default Value:
0.0
endLevel ViReal64 Sets the end level of the current or voltage ramp waveform output.
Valid Range:
Voltage: -210V to 210V
Current: -3.03A to 3.03A
Default Value:
0.0
startTime ViReal64 Sets the start time of the current or voltage ramp waveform output.
Valid Range:
0 to 1000 seconds
Default Value:
0
endTime ViReal64 Sets the end time of the current or voltage ramp waveform output.
Valid Range:
0 to 1000 seconds
Default Value:
0

agb2900_ConfigureLimitTestResultBitPattern

ViStatus agb2900_ConfigureLimitTestResultBitPattern (ViSession instrumentHandle, ViInt32 channel, ViInt32 testNumber, ViInt32 passPattern, ViInt32 lowerExceedingLimitFailure, ViInt32 upperExceedingLimitFailure, ViInt32 complianceFailurePattern);

Purpose

Configures the limit test result pattern.
Note:
This function is not applicable for B296x family models B2961A/B2962A, B2961B/B2962B, and B2961C/B2962C.

Parameters

Input
Name Type Description
instrumentHandle ViSession The ViSession handle that you obtain from the agb2900_Initialize function.  The handle identifies a particular instrument session that can be passed to other functions.
Default Value:  None
channel ViInt32 Specified channel to perform action.
Valid Values:
AGB2900_INSTRUMENT_CHANNEL_1: Channel 1 (B2901BL, B2910BL, B2901B, B2911B, B2961B)
AGB2900_INSTRUMENT_CHANNEL_2: Channel 2 (B2902B, B2912B, B2962B)
Default Value:
AGB2900_INSTRUMENT_CHANNEL_1: Channel 1
testNumber ViInt32 An integer used to specify a limit test to apply configuration.
Valid Range:
1~12
Default Value:
1
passPattern ViInt32 A bit pattern used to indicate pass of the limit test specified by m. The bit pattern is used for the SORT composite limit test.
Valid Range:
0 to 16383
Default Value:
16383
lowerExceedingLimitFailure ViInt32 A bit pattern used to indicate failed-by-exceeding-lower-limit of the limit test specified by m. The bit pattern is used for the GRAD composite limit test.
Valid Range:
0 to 16383
Default Value:
16383
upperExceedingLimitFailure ViInt32 A bit pattern used to indicate failed-by-exceeding-upper-limit of the limit test specified by m. The bit pattern is used for the GRAD composite limit test.
Valid Range:
0 to 16383
Default Value:
16383
complianceFailurePattern ViInt32 A bit pattern used to indicate failure of the compliance status check specified by m.
Valid Range:
0 to 16383
Default Value:
16383

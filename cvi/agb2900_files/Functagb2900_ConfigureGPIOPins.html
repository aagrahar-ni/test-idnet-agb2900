agb2900_ConfigureGPIOPins

ViStatus agb2900_ConfigureGPIOPins (ViSession instrumentHandle, ViInt32 IOFuction, ViInt32 pinNumber, ViInt32 functionPolarity, ViInt32 triggerTiming, ViInt32 triggerType, ViReal64 triggerPlusWidth);

Purpose

Configure GPIO(General Purpose I/O) Pin, which is an I/O port of the Digital I/O D-sub connector on the rear panel. Can be used as trigger input/output terminals or as an interface to a handler or the likes.

Parameters

Input
Name Type Description
instrumentHandle ViSession The ViSession handle that you obtain from the agb2900_Initialize function.  The handle identifies a particular instrument session that can be passed to other functions.
Default Value:  None
IOFuction ViInt32 The input/output function to the specified GPIO pin.
Valid Values:
IO Function = DINP assigns the digital input.
IO Function = DIO  assigns the digital I/O.
IO Function = HVOL assigns the high voltage status output. Only for the EXT14 pin.
IO Function = TINP assigns the trigger input.
IO Function = TOUT assigns the trigger output.
Default Value:
DINP (default for the EXT1 to EXT13 pins)
HVOL (default for the EXT14 pin)
pinNumber ViInt32 Specified GPIO pin number to apply configuration.
Valid Range:
1~14
Default Value:
1
functionPolarity ViInt32 The polarity of the input/output function for the specified GPIO pin.
Valid Values:
AGB2900_PIN_FUNCTION_POLARITY_POSITIVE: Positive. Sets the positive polarity.
AGB2900_PIN_FUNCTION_POLARITY_NEGATIVE: Negative. Sets the negative polarity.
Default Value:
AGB2900_PIN_FUNCTION_POLARITY_POSITIVE: Positive
triggerTiming ViInt32 Specified output trigger timing of the specified channel.
Valid Values:
AGB2900_TRIGGER_TIMING_BEFORE: Before. Enables the trigger output at the beginning of arm, trigger, and device action (transient or acquire).
AGB2900_TRIGGER_TIMING_AFTER: After. Enables the trigger output at the end of arm, trigger, and device action (transient or acquire).
AGB2900_TRIGGER_TIMING_BOTH: Both. Enables the trigger output at both the beginning and the end of arm, trigger, and device action (transient or acquire).
Default Value:
AGB2900_TRIGGER_TIMING_BOTH: Both
triggerType ViInt32 The output trigger type for the specified GPIO pin.
Valid Values:
AGB2900_TRIGGER_TYPE_EDGE: Edge. Selects the Edge trigger.
AGB2900_TRIGGER_TYPE_LEVEL: Level. Selects the Level trigger.
Default Value:
AGB2900_TRIGGER_TYPE_EDGE: Edge
triggerPlusWidth ViReal64 The pulse width of the output trigger.
Valid Range:
1E-5 to 1E-2 seconds
Default Value:
1.00E-04 seconds

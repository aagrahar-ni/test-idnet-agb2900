agb2900_ConfigureLXIForARMTrigger

ViStatus agb2900_ConfigureLXIForARMTrigger (ViSession instrumentHandle, ViInt32 LXIEvent, ViBoolean enableLXIEvent, ViInt32 LXIEventType, ViInt32 LXIEventDetection, ViInt32 LXIEventSource, ViChar _VI_FAR LXIEventDestination[]);

Purpose

Configures the LXI Trigger Event for trigger layer or ARM layer.  
To use LXI Triggers, set the trigger source to LAN first.

Parameters

Input
Name Type Description
instrumentHandle ViSession The ViSession handle that you obtain from the agb2900_Initialize function.  The handle identifies a particular instrument session that can be passed to other functions.
Default Value:  None
LXIEvent ViInt32 Specify the LAN Event to configure.
Valid Values:
AGB2900_LXI_EVENT_LAN0: LAN0
AGB2900_LXI_EVENT_LAN1: LAN1
AGB2900_LXI_EVENT_LAN2: LAN2
AGB2900_LXI_EVENT_LAN3: LAN3
AGB2900_LXI_EVENT_LAN4: LAN4
AGB2900_LXI_EVENT_LAN5: LAN5
AGB2900_LXI_EVENT_LAN6: LAN6
AGB2900_LXI_EVENT_LAN7: LAN7
Default Value:
AGB2900_LXI_EVENT_LAN0: LAN0
enableLXIEvent ViBoolean Enable or disable the LXI trigger event output.
Valid Range:
VI_TRUE - Enabled
VI_FALSE - Disabled
Default Value:
VI_FALSE
LXIEventType ViInt32 Specify the LXI event type.
Valid Values:
AGB2900_LXI_EVENT_TYPE_ARM: ARM
AGB2900_LXI_EVENT_TYPE_TRIGGER: Trigger
Default Value:
AGB2900_LXI_EVENT_EDGE_RISE: Rise
LXIEventDetection ViInt32 Specify the LXI event detection.
Valid Values:
AGB2900_LXI_EVENT_DETECTION_RISE: Rise
AGB2900_LXI_EVENT_DETECTION_FALL: Fall
AGB2900_LXI_EVENT_DETECTION_HIGH: High
AGB2900_LXI_EVENT_DETECTION_LOW: Low
Default Value:
AGB2900_LXI_EVENT_EDGE_RISE: Rise
LXIEventSource ViInt32 An instrument-specific discrete value that specified LAN ARM-Trigger event is tied to.
Valid Values:
AGB2900_LXI_EVENT_SOURCE_WAIT_FOR_ACQUIRE_ARM1: Waiting For Acquire Arm1
AGB2900_LXI_EVENT_SOURCE_WAIT_FOR_TRANSITION_ARM1: Waiting For Transition Arm1
AGB2900_LXI_EVENT_SOURCE_WAIT_FOR_ACQUIRE_ARM2: Waiting For Acquire Arm2
AGB2900_LXI_EVENT_SOURCE_WAIT_FOR_TRANSITION_ARM2: Waiting For Transition Arm2
AGB2900_LXI_EVENT_SOURCE_WAIT_FOR_ACQUIRE_TRIGGER1: Waiting For Acquire Trigger1
AGB2900_LXI_EVENT_SOURCE_WAIT_FOR_TRANSITION_TRIGGER1: Waiting For Transition Trigger1
AGB2900_LXI_EVENT_SOURCE_WAIT_FOR_ACQUIRE_TRIGGER2: Waiting For Acquire Trigger2
AGB2900_LXI_EVENT_SOURCE_WAIT_FOR_TRANSITION_TRIGGER2: Waiting For Transition Trigger2
AGB2900_LXI_EVENT_SOURCE_MEASURING1: Measuring1
AGB2900_LXI_EVENT_SOURCE_SETTLING1: Settling1
AGB2900_LXI_EVENT_SOURCE_MEASURING2: Measuring2
AGB2900_LXI_EVENT_SOURCE_SETTLING2: Settling2
Default Value:
AGB2900_LXI_EVENT_SOURCE_WAIT_FOR_ACQUIRE_ARM1: Waiting For Acquire Arm1
LXIEventDestination ViChar[] Specify the LXI event destination. It contains destination host name, LAN identifier and port number.
Valid Values:
Up to 32 ASCII characters.
Default Value:
VI_NULL

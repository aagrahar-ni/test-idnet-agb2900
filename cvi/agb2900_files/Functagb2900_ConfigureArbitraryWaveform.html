agb2900_ConfigureArbitraryWaveform

ViStatus agb2900_ConfigureArbitraryWaveform (ViSession instrumentHandle, ViInt32 channel, ViInt32 shapeOfWaveform, ViReal64 numberOfWaveforms);

Purpose

Configures the arbitrary waveform output.
Note:
This function is only supported by B296x family models B2961A/B2962A, B2961B/B2962B, and B2961C/B2962C.

Parameters

Input
Name Type Description
instrumentHandle ViSession The ViSession handle that you obtain from the agb2900_Initialize function.  The handle identifies a particular instrument session that can be passed to other functions.
Default Value:  None
channel ViInt32 Specified channel to perform action.
Valid Values:
AGB2900_INSTRUMENT_CHANNEL_1: Channel 1 (B2901BL, B2910BL, B2901B, B2911B, B2961B)
AGB2900_INSTRUMENT_CHANNEL_2: Channel 2 (B2902B, B2912B, B2962B)
Default Value:
AGB2900_INSTRUMENT_CHANNEL_1: Channel 1
shapeOfWaveform ViInt32 Selects the shape of the arbitrary waveform output for the specified source channel.
Valid Values:
AGB2900_WAVEFORM_SHAPE_EXPONENTIAL: Exponential (EXP). Selects the exponential current or voltage waveform.
AGB2900_WAVEFORM_SHAPE_RAMP: Ramp (RAMP). Selects the ramp current or voltage waveform.
AGB2900_WAVEFORM_SHAPE_SINUSOID: Sinusoid (SIN). Selects the sinusoidal current or voltage waveform.
AGB2900_WAVEFORM_SHAPE_SQUARE: Square (SQU). Selects the square current or voltage waveform.
AGB2900_WAVEFORM_SHAPE_TRAPEZOID: Trapezoid (TRAP). Selects the trapezoidal current or voltage waveform.
AGB2900_WAVEFORM_SHAPE_TRIANGLE: Triangle (TRI). Selects the triangle current or voltage waveform.
AGB2900_WAVEFORM_SHAPE_USERDEFINED: User Defined (UDEF). Selects the user defined current or voltage waveform.
Default Value:
AGB2900_WAVEFORM_SHAPE_SQUARE: Square
numberOfWaveforms ViReal64 Sets the number of arbitrary waveform s for the current or voltage output.
Valid Range:
1 to 100000 or 2147483647
Default Value:
1
NOTE: Data must be less than 100001, and 2147483647 indicates infinity.

Return Value

Name Type Description

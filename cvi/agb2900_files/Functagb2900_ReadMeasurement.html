agb2900_ReadMeasurement

ViStatus agb2900_ReadMeasurement (ViSession instrumentHandle, ViInt32 channelList, ViInt32 dataMode, ViInt32 maxTime, ViPReal64 measuredValue);

Purpose

Executes the agb2900_Initiate and agb2900_FetchMeasurement function in series, and returns the latest voltage measurement data, current measurement data, resistance measurement data, time data, status data, or source output setting data specified by the :FORMat:ELEMents:SENSe command. The data is not cleared until the :INITiate, :MEASure, or :READ command is executed.

Parameters

Input
Name Type Description
instrumentHandle ViSession The ViSession handle that you obtain from the agb2900_Initialize function.  The handle identifies a particular instrument session that can be passed to other functions.
Default Value:  None
channelList ViInt32 Specified channel to perform action.
Valid Values:
AGB2900_INSTRUMENT_CHANNEL_1: Channel 1 (B2901BL, B2910BL, B2901B, B2911B, B2961B)
AGB2900_INSTRUMENT_CHANNEL_2: Channel 2 (B2902B, B2912B, B2962B)
AGB2900_INSTRUMENT_CHANNEL_BOTH: Both(B2912A, B2902A, B2901B/B2902B, B2911B/B2912B, B2961B/B2962B)
Default Value:
AGB2900_INSTRUMENT_CHANNEL_1: Channel 1
dataMode ViInt32 Specifies the data mode.
Valid Values:
AGB2900_DATA_MODE_VOLTAGE: Voltage
AGB2900_DATA_MODE_CURRENT: Current
AGB2900_DATA_MODE_RESISTANCE: Resistance
AGB2900_DATA_MODE_SOURCE: Source
AGB2900_DATA_MODE_STATUS: Status
AGB2900_DATA_MODE_TIME: Time
Default Value:
AGB2900_DATA_MODE_VOLTAGE: Voltage
maxTime ViInt32 Specifies the maximum time, in milliseconds, to wait for the operation to complete.
Valid Range:
1 to 4294967295(2^32 - 1)
Default Value:
10000 ms
Output
Name Type Description
measuredValue ViReal64 (passed by reference) Initiate and fetch the latest data in series.

Return Value

Name Type Description
status ViStatus Returns the status code of this operation.  The status code indicates success or describes an error or warning condition. You can examine the status code from each call to an instrument driver function to determine whether an error occurred.
To obtain a description of the last error, call the agb2900_ErrorMessage function.
In general, you can interpret status codes as follows:
Value                  Meaning
-------------------------------
0                      Success
Positive Values        Warnings
Negative Values        Errors
This driver defines the following status codes:
Status    Description
-------------------------------------------------
No defined status codes.
This instrument driver also returns errors and warnings defined by other sources.  The following table defines additional status code ranges that this driver can return.
Numeric Range (in Hex)   Status Code Types    
-------------------------------------------------
3FFF0000 to 3FFFFFFF     VISA     Warnings
3FFC0000 to 3FFCFFFF     VXIPnP   Driver Warnings
BFFF0000 to BFFFFFFF     VISA     Errors
BFFC0000 to BFFCFFFF     VXIPnP   Driver Errors

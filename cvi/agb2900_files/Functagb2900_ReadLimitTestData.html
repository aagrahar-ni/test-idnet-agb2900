agb2900_ReadLimitTestData

ViStatus agb2900_ReadLimitTestData (ViSession instrumentHandle, ViInt32 channel, ViInt32 offset, ViInt32 size, ViBoolean acquireNullOffsetEnabled, ViPReal64 calculationData, ViPReal64 timeStamp, ViPReal64 status, ViBoolean _VI_FAR testFailed[], ViInt32 testFailedSize);

Purpose

Calculates the limit test data.
Note:
Commands in the conditional statement are not applicable for B296x family models B2961A/B2962A, B2961B/B2962B, and B2961C/B2962C.

Parameters

Input
Name Type Description
instrumentHandle ViSession The ViSession handle that you obtain from the agb2900_Initialize function.  The handle identifies a particular instrument session that can be passed to other functions.
Default Value:  None
channel ViInt32 Specified channel to perform action.
Valid Values:
AGB2900_INSTRUMENT_CHANNEL_1: Channel 1 (B2901BL, B2910BL, B2901B, B2911B, B2961B)
AGB2900_INSTRUMENT_CHANNEL_2: Channel 2 (B2902B, B2912B, B2962B)
Default Value:
AGB2900_INSTRUMENT_CHANNEL_1: Channel 1
offset ViInt32 Beginning of data to receive. offset=n specifies the (n+1)th data.  Value 0 specifies the present data position.  
Valid Range:
0 to maximum (depends on the buffer state).
Default Value:
0
size ViInt32 Number of data to receive. Value 0 means all data from offset is returned.
Valid Range:
1 to maximum (depends on the buffer state).
Default Value:
1
acquireNullOffsetEnabled ViBoolean Whether or not automatically set the null offset value used for calculating the limit test data.
Valid Range:
VI_TRUE - Enabled. When auto-set enabled, the null offset value will be acquired immediately.
VI_FALSE - Disabled. When auto-set disabled, the null offset value is specified by Configure Limit Test Null Offset.vi.
Default Value:
VI_FALSE (Disable)
Note:
When enabled, the null offset value is acquired only once and you need to reconfigure the auto-set value to ON if you want to acquire again.
testFailedSize ViInt32 Sets the size of test failed.
Valid Range:
1 to 12
Default Value:
1
Output
Name Type Description
calculationData ViReal64 (passed by reference) Calculation Result.
timeStamp ViReal64 (passed by reference) Time stamp of calculation data.
status ViReal64 (passed by reference) Status data is given by a binary-weighted sum of all bits set in the binary data.
Bit Definitions of Status Data
bit 0 - Source (0: Voltage; 1: Current)
bit 1 and 2 - Compliance condition(0: No; 1, 2, 3: Yes)
bit 3 - Over voltage condition(0: No; 1: Yes)
bit 4 - Over current condition(0: No; 1: Yes)
bit 5 - High temperature condition(0: No; 1: Yes)
bit 13 - Measurement range overflow(0: No; 1: Yes)
bit 14 - Offset compensation enable condition(0: No; 1: Yes)
bit 15 - Contact check failure(0: No; 1: Yes)
bit 16 to 20 - Limit test result, 0 to 31
testFailed ViBoolean[] An array of 12 boolean indicates the results of Limit Tests
True - Passed
False - Failed

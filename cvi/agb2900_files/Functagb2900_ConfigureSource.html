agb2900_ConfigureSource

ViStatus agb2900_ConfigureSource (ViSession instrumentHandle, ViInt32 channel, ViInt32 outputMode, ViInt32 outputFunction, ViReal64 outputLevel, ViReal64 triggerOutputLevel, ViReal64 outputRange, ViBoolean continuousTriggerEnabled);

Purpose

Configures output level, output mode, and enables or disables the output for specified channel of the power sourcing.

Parameters

Input
Name Type Description
instrumentHandle ViSession The ViSession handle that you obtain from the agb2900_Initialize function.  The handle identifies a particular instrument session that can be passed to other functions.
Default Value:  None
channel ViInt32 Specified channel to perform action.
Valid Values:
AGB2900_INSTRUMENT_CHANNEL_1: Channel 1 (B2901BL, B2910BL, B2901B, B2911B, B2961B)
AGB2900_INSTRUMENT_CHANNEL_2: Channel 2 (B2902B, B2912B, B2962B)
Default Value:
AGB2900_INSTRUMENT_CHANNEL_1: Channel 1
outputMode ViInt32 The source output mode of the specified channel.
Valid Values:
AGB2900_SOURCE_OUTPUT_MODE_CURRENT: Current. Sets the specified channel to the current source.
AGB2900_SOURCE_OUTPUT_MODE_VOLTAGE: Voltage. Sets the specified channel to the voltage source.
Default Value:
AGB2900_SOURCE_OUTPUT_MODE_VOLTAGE: Voltage
outputFunction ViInt32 The source output shape of the specified channel.
Valid Values:
AGB2900_SOURCE_OUTPUT_FUNCTION_PLUS: Pulse Sets the specified channel to the const output.(Pulse output is not available for B2901BL and B2910BL)
AGB2900_SOURCE_OUTPUT_FUNCTION_DC: DC Sets the specified channel to the pulsed output.                                     
Default Value: AGB2900_SOURCE_OUTPUT_FUNCTION_DC: DC

triggerOutputLevel ViReal64 The output level of the specified source channel which will be changed immediately by receiving a trigger source set by ConfigureTrigger function.
Valid Range:
Refer the help context for OutputLevel.
Default Value:

outputRange ViReal64 The current or voltage output range of the specified source channel. This command is effective when the automatic ranging function is off.
Valid Range:
10nA to 10A: For current output. See help context of Output Level.
0.2V to 200V: For voltage output. See help context of Output Level.
Default Value:
2 V
continuousTriggerEnabled ViBoolean Expected status of continuous trigger output for the specified channel
Valid Range:
VI_TRUE  - Enables the continuous trigger output. The specified channel keeps the output level and range settings even after the grouped channels change the status from busy to idle.
VI_FALSE - Disables the continuous trigger output. The specified channel changes the output level and range settings to the previous settings immediately when the grouped channels change the status from busy to idle.
Default Value:
VI_TRUE

In general, you can interpret status codes as follows:

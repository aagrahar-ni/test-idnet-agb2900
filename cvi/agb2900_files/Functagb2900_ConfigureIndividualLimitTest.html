agb2900_ConfigureIndividualLimitTest

ViStatus agb2900_ConfigureIndividualLimitTest (ViSession instrumentHandle, ViInt32 channel, ViInt32 testNumber, ViBoolean enableIndividualLimitTest, ViReal64 lowerLimit, ViReal64 upperLimit, ViInt32 testType, ViInt32 feedMode, ViInt32 judgementCriteria);

Purpose

Configures the properties of specified limit test. The limit test means a pass/fail judgment performed while a composite limit test. The limit test result is returned by Read Limit Test Result
Note:
This function is not applicable for B296x family models B2961A/B2962A, B2961B/B2962B, and B2961C/B2962C.

Parameters

Input
Name Type Description
instrumentHandle ViSession The ViSession handle that you obtain from the agb2900_Initialize function.  The handle identifies a particular instrument session that can be passed to other functions.
Default Value:  None
channel ViInt32 Specified channel to perform action.
Valid Values:
AGB2900_INSTRUMENT_CHANNEL_1: Channel 1 (B2901BL, B2910BL, B2901B, B2911B, B2961B)
AGB2900_INSTRUMENT_CHANNEL_2: Channel 2 (B2902B, B2912B, B2962B)
Default Value:
AGB2900_INSTRUMENT_CHANNEL_1: Channel 1
testNumber ViInt32 An integer used to specify a limit test to apply configuration.
Valid Range:
1~12
Default Value:
1
enableIndividualLimitTest ViBoolean Expected status of the specified limit test.
Valid Range:
VI_TRUE:  Enabled
VI_FALSE: Disabled
Default Value:
VI_FALSE
lowerLimit ViReal64 A lower limit used for the specified limit test.
Valid Range:
-9.999999E+20 to +9.999999E+20
Default Value:
-1
upperLimit ViReal64 An upper limit used for the specified limit test.
Valid Range:
-9.999999E+20 to +9.999999E+20
Default Value:
1
testType ViInt32 Expected type of the specified limit test.
Valid Values:
AGB2900_LIMIT_TEST_TYPE_COMPLIANCE: Compliance. Sets the compliance status check which checks if the channel is in the compliance status.
AGB2900_LIMIT_TEST_TYPE_LIMIT: Limit. Sets the limit test which checks if the measurement value is between the upper limit and the lower limit.
Default Value:
AGB2900_LIMIT_TEST_TYPE_LIMIT: Limit
feedMode ViInt32 Specify which input data is used to calculate the limit test data.
Valid Values:
AGB2900_LIMIT_TEST_FEED_MODE_VOLTAGE:    Voltage. Specifies the voltage measurement data.
AGB2900_LIMIT_TEST_FEED_MODE_CURRENT:    Current. Specifies the current measurement data.
AGB2900_LIMIT_TEST_FEED_MODE_RESISTANCE: Resistance. Specifies the resistance calculation data given by the following formula.
Resistance=Vmeas/Imeas
Where, Vmeas is the voltage measurement data, and Imeas is the current measurement data.
AGB2900_LIMIT_TEST_FEED_MODE_MATH: Math. Specifies the data given by a math expression. Use Configure Math Expression.vi before this VI to define a new expression or edit an old expression.
Default Value:
AGB2900_LIMIT_TEST_FEED_MODE_VOLTAGE: Voltage
judgementCriteria ViInt32 The judgment criteria of the specified Limit Test.
Valid Values:
AGB2900_LIMIT_TEST_JUDGEMENT_CRITERIA_IN: IN. Judges limit test failure if the channel goes into the compliance state.
AGB2900_LIMIT_TEST_JUDGEMENT_CRITERIA_OUT: OUT. Judges it failure if the channel gets out of the compliance state.
Default Value:
AGB2900_LIMIT_TEST_JUDGEMENT_CRITERIA_IN: IN
Note:
This property is only valid when Limit Test Type for specified limit test is set to Compliance.

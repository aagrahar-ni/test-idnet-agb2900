agb2900_ConfigureARMLayerTrigger

ViStatus agb2900_ConfigureARMLayerTrigger (ViSession instrumentHandle, ViInt32 channel, ViInt32 deviceAction, ViInt32 ARMTriggerSource, ViInt32 ARMCount, ViInt32 ARMDelay, ViReal64 ARMTimerInterval, ViBoolean ARMBypassEnabled, ViBoolean _VI_FAR LXITriggers[], ViInt32 arraySize);

Purpose

Configure the ARM layer trigger in ARM-Trigger model. B2900 supports the ARM-Trigger model described in 1999 SCPI Command Reference. The ARM-Trigger model shows independent event detection for the ARM and Trigger layers.

Parameters

Input
Name Type Description
instrumentHandle ViSession The ViSession handle that you obtain from the agb2900_Initialize function.  The handle identifies a particular instrument session that can be passed to other functions.
Default Value:  None
channel ViInt32 Specified channel to perform action.
Valid Values:
AGB2900_INSTRUMENT_CHANNEL_1: Channel 1 (B2901B, B2911B, B2961B, B2901BL, B2910BL)
AGB2900_INSTRUMENT_CHANNEL_2: Channel 2 (B2902B, B2912B, B2962B)
Default Value:
AGB2900_INSTRUMENT_CHANNEL_1: Channel 1
deviceAction ViInt32 For what device action to send trigger.
Valid Values:
AGB2900_DEVICE_ACTION_ACQUIRE: Acquire. For measurement action.
AGB2900_DEVICE_ACTION_TRANSIENT: Transient. For source output action.
AGB2900_DEVICE_ACTION_BOTH: Both. For both device action.
Default Value:
AGB2900_DEVICE_ACTION_BOTH (Both).
ARMTriggerSource ViInt32 Expected trigger source for the specified device action.
Valid Values:
AGB2900_TRIGGER_SOURCE_AINT: AINT (automatic internal). Automatically selects the trigger source most suitable for the present operating mode by using the internal algorithms.
AGB2900_TRIGGER_SOURCE_BUS: BUS. Selects the remote interface trigger. Use Send Software Trigger.vi to send trigger.
AGB2900_TRIGGER_SOURCE_TIMER: Timer. Selects a signal internally generated every interval set by the Timer Trigger Interval control.
AGB2900_TRIGGER_SOURCE_INT1: INT1. Selects the output of the channel 1 or 2 respectively. Available only for the 2-channel model.
AGB2900_TRIGGER_SOURCE_INT2: INT2.
AGB2900_TRIGGER_SOURCE_LAN: LAN. Selects LXI triggers specified by LXI Triggers Status Control.
AGB2900_TRIGGER_SOURCE_EXT1: EXT1. Selects a signal from the GPIO pin n which is an output port of the Digital I/O D-sub connector on the rear panel.
AGB2900_TRIGGER_SOURCE_EXT2: EXT2.
AGB2900_TRIGGER_SOURCE_EXT3: EXT3.
AGB2900_TRIGGER_SOURCE_EXT4: EXT4.
AGB2900_TRIGGER_SOURCE_EXT5: EXT5.
AGB2900_TRIGGER_SOURCE_EXT6: EXT6.
AGB2900_TRIGGER_SOURCE_EXT7: EXT7.
AGB2900_TRIGGER_SOURCE_EXT8: EXT8.
AGB2900_TRIGGER_SOURCE_EXT9: EXT9.
AGB2900_TRIGGER_SOURCE_EXT10: EXT10.
AGB2900_TRIGGER_SOURCE_EXT11: EXT11.
AGB2900_TRIGGER_SOURCE_EXT12: EXT12.
AGB2900_TRIGGER_SOURCE_EXT13: EXT13.
AGB2900_TRIGGER_SOURCE_EXT14: EXT14.
Default Value:
AGB2900_TRIGGER_SOURCE_AINT: AINT
ARMCount ViInt32 Sets the ARM trigger count for the specified device action.
Valid Range:
Min: 1
Max: 100000 or 2147483647
For B2901BL and B2901CL,
Valid Range:
Min: 1
Max: 10000.
Default Value:
1
Note(s):
1) Infinity is not available for B2901BL, B2910BL, B2901CL and B2910CL.
ARMDelay ViInt32 Sets the ARM trigger delay for the specified device action.
Valid Range: (For Models B2901BL, B2910BL, B2901B, B2911B, B2961B, B2902B, B2912B, B2962B)
0 to 100000 seconds
Valid Range for other Models:
0 to 100
Default Value:
0 second
ARMTimerInterval ViReal64 Expected interval of the Timer arm source for the specified device action.
Valid Range:
B2901BL/B2901CL: 2E-4 to 1E+5
B2910BL/B2910CL: 5E-5 to 1E+5
B2901B/B2902B/B2901C/B2902C: 2E-5 to 1E+5
B2911B/B2912B/B2911C/B2912C: 1E-5 to 1E+5
B2961B/B2962B/B2961C/B2962C: 1E-5 to 1E+5
Default Value:
5E-5 seconds
For other Models:
Valid Range: 1E-5 to 1E+5
Default value: 1E+5
ARMBypassEnabled ViBoolean Enables or disables a bypass for the event detector in the trigger layer.
Valid Range:
VI_TRUE  - Enable
VI_FALSE - Disable
Default Value: VI_FALSE
LXITriggers ViBoolean[] An eight values array specifies whether or not the according LXI triggers are used for the ARM trigger source for the specified device action. Index of 0 to 7 corresponds to LXI Trigger LAN0 to 7.   
Valid Range for Element:
TRUE: Used
FALSE: Not Used
arraySize ViInt32 Array size of the parameter LXITriggers.
Valid Range:
1 to 8
Default Value:
1

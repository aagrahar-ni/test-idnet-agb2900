agb2900_ConfigureWaveformUserDefined

ViStatus agb2900_ConfigureWaveformUserDefined (ViSession instrumentHandle, ViInt32 channel, ViInt32 outputMode, ViReal64 stepTime, ViInt32 listOutputDataMode, ViReal64 _VI_FAR listOfOutputData[], ViInt32 listOutputDataSize, ViBoolean enableTriggerOutput, ViInt32 triggerOutputPort, ViInt32 listTriggerOutputMode, ViBoolean _VI_FAR listOfTriggerOutput[], ViInt32 listTriggerOutputSize);

Purpose

Configures current or voltage user defined waveform output.
Note:
This function is only supported by B296x family models B2961A/B2962A, B2961B/B2962B, and B2961C/B2962C.

Parameters

Input
Name Type Description
instrumentHandle ViSession The ViSession handle that you obtain from the agb2900_Initialize function. The handle identifies a particular instrument session that can be passed to other functions.
Default Value: None
channel ViInt32 Specified channel to perform action.
Valid Values:
AGB2900_INSTRUMENT_CHANNEL_1: Channel 1 (B2901BL, B2910BL, B2901B, B2911B, B2961B)
AGB2900_INSTRUMENT_CHANNEL_2: Channel 2 (B2902B, B2912B, B2962B)
Default Value:
AGB2900_INSTRUMENT_CHANNEL_1: Channel 1
outputMode ViInt32 Sets the source output mode of the specified channel.
Valid Values:
AGB2900_SOURCE_OUTPUT_MODE_CURRENT: Current. Sets the specified channel to the current source.
AGB2900_SOURCE_OUTPUT_MODE_VOLTAGE: Voltage. Sets the specified channel to the voltage source.
Default Value:
AGB2900_SOURCE_OUTPUT_MODE_VOLTAGE: Voltage
stepTime ViReal64 Sets the step time of the user defined waveform.
Valid Range:
1E-5 to 1000 seconds
Default Value:
1E-5
listOutputDataMode ViInt32 Specifies the mode to apply list output data.
Valid Values:
AGB2900_LIST_OUTPUT_DATA_MODE_APPEND: Append. Append the list data to existing list.
AGB2900_LIST_OUTPUT_DATA_MODE_NEW: New List. Delete old list, use specified list data as  fresh new list.
Default Value:
AGB2900_LIST_OUTPUT_DATA_MODE_NEW: New List
listOfOutputData ViReal64[] Sets the current or voltage output data for each point of the user defined waveform for the specified channel.
Valid Range:
Maximum of 100000 data can be set to list. Each data must be separated by a comma, for example: list=0.1,0.2,0.3.
Default Value:
VI_NULL
listOutputDataSize ViInt32 Sets the number of output data for list output data.
Valid Range:
1 to 100000
Default Value:
1
enableTriggerOutput ViBoolean Enables or disables the trigger output for the user defined waveform output.
Valid Values:
VI_TRUE:  Enable. Enables the trigger output.
VI_FALSE: Disable. Disables the trigger output.
Default Value:
VI_TRUE: Enable
triggerOutputPort ViInt32 Selects the trigger output for the user defined waveform. Multiple trigger output ports can be set.
Valid Values:
AGB2900_TRIGGER_OUTPUTPORT_EXT1: External1
AGB2900_TRIGGER_OUTPUTPORT_EXT2: External2
AGB2900_TRIGGER_OUTPUTPORT_EXT3: External3
AGB2900_TRIGGER_OUTPUTPORT_EXT4: External4
AGB2900_TRIGGER_OUTPUTPORT_EXT5: External5
AGB2900_TRIGGER_OUTPUTPORT_EXT6: External6
AGB2900_TRIGGER_OUTPUTPORT_EXT7: External7
AGB2900_TRIGGER_OUTPUTPORT_EXT8: External8
AGB2900_TRIGGER_OUTPUTPORT_EXT9: External9
AGB2900_TRIGGER_OUTPUTPORT_EXT10: External10
AGB2900_TRIGGER_OUTPUTPORT_EXT11: External11
AGB2900_TRIGGER_OUTPUTPORT_EXT12: External12
AGB2900_TRIGGER_OUTPUTPORT_EXT13: External13
AGB2900_TRIGGER_OUTPUTPORT_EXT14: External14
AGB2900_TRIGGER_OUTPUTPORT_INT1: Internal1
AGB2900_TRIGGER_OUTPUTPORT_INT2: Internal2
Default Value:
AGB2900_TRIGGER_OUTPUTPORT_EXT1: External1
listTriggerOutputMode ViInt32 Specifies the mode to apply list trigger output data.
Valid Values:
AGB2900_LIST_TRIGGER_OUTPUT_MODE_APPEND: Append. Append the list data to existing list.
AGB2900_LIST_TRIGGER_OUTPUT_MODE_NEW: New List. Delete old list, use specified list data as  fresh new list.
Default Value:
AGB2900_LIST_TRIGGER_OUTPUT_MODE_NEW: New List
listOfTriggerOutput ViBoolean[] Sets the trigger output status for each point of the current or voltage user defined waveform output.
Valid Range:
1 or ON:  For the point with trigger output.
0 or OFF: For the point without trigger output.
Maximum of 100000 data can be set to list. Each data must be separated by a comma, for example: list=0,1,0.
Default Value:
VI_NULL
listTriggerOutputSize ViInt32 Sets the number of output data for list trigger output.
Valid Range:
1 to 100000
Default Value:
1

agb2900_ConfigureSourceRangeMode

ViStatus agb2900_ConfigureSourceRangeMode (ViSession instrumentHandle, ViInt32 channel, ViInt32 sweepRangingMode);

Purpose

Configures sweep range mode for specified channel.

Parameters

Input
Name Type Description
instrumentHandle ViSession The ViSession handle that you obtain from the agb2900_Initialize function.  The handle identifies a particular instrument session that can be passed to other functions.
Default Value:  None
channel ViInt32 Specified channel to perform action.
Valid Values:
AGB2900_INSTRUMENT_CHANNEL_1: Channel 1 (B2901BL, B2910BL, B2901B, B2911B, B2961B)
AGB2900_INSTRUMENT_CHANNEL_2: Channel 2 (B2902B, B2912B, B2962B)
Default Value:
AGB2900_INSTRUMENT_CHANNEL_1: Channel 1
sweepRangingMode ViInt32 The output ranging mode of the sweep output for the specified channel.
Valid Values:
AGB2900_SWEEP_RANGING_MODE_BEST: BEST. The channel automatically sets the range which covers whole sweep output levels for the linear sweep or the range which provides the best resolution to apply the source output for each step of the log sweep.
AGB2900_SWEEP_RANGING_MODE_FIX: FIX. The channel automatically sets the range which provides the best resolution to apply the source output for each sweep step.
AGB2900_SWEEP_RANGING_MODE_AUTO: AUTO. The channel uses only the range effective when starting the sweep. Range change is not performed while the sweep output is applied.
Default Value:
AGB2900_SWEEP_RANGING_MODE_AUTO: AUTO

Return Value

Name Type Description

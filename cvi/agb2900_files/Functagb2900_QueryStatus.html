agb2900_QueryStatus

ViStatus agb2900_QueryStatus (ViSession instrumentHandle, ViInt32 registerType, ViPInt32 statusValue);

Purpose

Queries the value of the measurement, operation, or questionable status condition register.
Note:
Use this method only with other low-level methods.  The high-level methods automatically incorporate this functionality.

Parameters

Input
Name Type Description
instrumentHandle ViSession The ViSession handle that you obtain from the agb2900_Initialize function.  The handle identifies a particular instrument session that can be passed to other functions.
Default Value:  None
registerType ViInt32 Specified the register type.
Valid Values:
AGB2900_REGISTER_TYPE_QUESTIONABLE_STATUS_CONDITION: Questionable Status Condition Register.
AGB2900_REGISTER_TYPE_MEASUREMENT_STATUS_CONDITION : Measurement Status Condition Register.
AGB2900_REGISTER_TYPE_OPERATION_STATUS_CONDITION   : Operation Status Condition Register.
AGB2900_REGISTER_TYPE_QUESTIONABLE_CALIBRATION     : Questionable Calibration Register.
AGB2900_REGISTER_TYPE_QUESTIONABLE_CURRENT         : Questionable Current  Register.
AGB2900_REGISTER_TYPE_QUESTIONABLE_TEMPERATURE     : Questionable Temperature Register.
AGB2900_REGISTER_TYPE_QUESTIONABLE_TEST            : Questionable Test Register.
AGB2900_REGISTER_TYPE_QUESTIONABLE_VOLTAGE         : Questionable Voltage Register.
Default value:
AGB2900_REGISTER_TYPE_QUESTIONABLE_STATUS_CONDITION: Questionable Status Condition Register.
Output
Name Type Description
statusValue ViInt32 (passed by reference) This value indicate the specified register status.

Return Value

Name Type Description
status ViStatus Returns the status code of this operation.  The status code indicates success or describes an error or warning condition. You can examine the status code from each call to an instrument driver function to determine whether an error occurred.
To obtain a description of the last error, call the agb2900_ErrorMessage function.
In general, you can interpret status codes as follows:
Value                  Meaning
-------------------------------
0                      Success
Positive Values        Warnings
Negative Values        Errors
This driver defines the following status codes:
Status    Description
-------------------------------------------------
No defined status codes.
This instrument driver also returns errors and warnings defined by other sources.  The following table defines additional status code ranges that this driver can return.
Numeric Range (in Hex)   Status Code Types    
-------------------------------------------------
3FFF0000 to 3FFFFFFF     VISA     Warnings
3FFC0000 to 3FFCFFFF     VXIPnP   Driver Warnings
BFFF0000 to BFFFFFFF     VISA     Errors
BFFC0000 to BFFCFFFF     VXIPnP   Driver Errors

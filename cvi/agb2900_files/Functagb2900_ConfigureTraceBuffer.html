agb2900_ConfigureTraceBuffer

ViStatus agb2900_ConfigureTraceBuffer (ViSession instrumentHandle, ViInt32 channel, ViInt32 bufferSize, ViInt32 bufferDataType, ViInt32 bufferControl, ViInt32 timeRule);

Purpose

Configures the Trace Buffer.
Note:":TRAC[c]:FEED LIM" is not applicable for B296x family models B2961A/B2962A, B2961B/B2962B, and B2961C/B2962C.

Parameters

Input
Name Type Description
instrumentHandle ViSession The ViSession handle that you obtain from the agb2900_Initialize function.  The handle identifies a particular instrument session that can be passed to other functions.
Default Value:  None
channel ViInt32 Specified channel to perform action.
Valid Values:
AGB2900_INSTRUMENT_CHANNEL_1: Channel 1 (B2901BL, B2910BL, B2901B, B2911B, B2961B)
AGB2900_INSTRUMENT_CHANNEL_2: Channel 2 (B2902B, B2912B, B2962B)
Default Value:
AGB2900_INSTRUMENT_CHANNEL_1: Channel 1
bufferSize ViInt32 The size of the trace buffer. This value is effective only when the Trace Buffer Control is set to Never.
For B2901BL,
Valid Range : 1 to 10000
Default: 10000
For Other Models,
Valid Range : 1 to 100000
Default: 100000
bufferDataType ViInt32 Expected data to feed, which specifies the data placed in the trace buffer. This setting is effective when the Trace Buffer Control is set to Never.
Valid Values:
AGB2900_BUFFER_DATA_TYPE_MATH :  Math. The calculation result data.
AGB2900_BUFFER_DATA_TYPE_LIMIT: Limit. The limit test data. (Not available for B2961A, B2962A, B2961B and B2962B.
AGB2900_BUFFER_DATA_TYPE_SENSE: Sense. The measurement result data.
Default Value:
AGB2900_BUFFER_DATA_TYPE_SENSE: Sense
bufferControl ViInt32 Expected control of trace buffer.
Valid Values:
AGB2900_BUFFER_CONTROL_NEXT: Next. Enables the write operation until buffer full. The buffer full causes an error.
AGB2900_BUFFER_CONTROL_NEVER: Never. Disables the write operation to the trace buffer.
Default Value:
AGB2900_BUFFER_CONTROL_NEVER: Never
timeRule ViInt32 The rule for reading the timestamp data in the trace buffer.
Valid Values:
AGB2900_TIME_RULE_DELTA: Delta. The returned data is set to the incremental value for the previous timestamp data.
AGB2900_TIME_RULE_ABSOLUTE: Absolute. The returned data is set to the incremental value for the first timestamp data.
Default Value:
AGB2900_TIME_RULE_ABSOLUTE: Absolute

Return Value

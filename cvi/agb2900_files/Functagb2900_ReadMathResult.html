agb2900_ReadMathResult

ViStatus agb2900_ReadMathResult (ViSession instrumentHandle, ViInt32 channel, ViPReal64 calculationData, ViPReal64 timeStamp, ViPReal64 status);

Purpose

Calculate specified math expression and return the result.
Note:
If the math expression contains some measurement results, measurement may be performed many times to obtain the result. For example, measurement must be performed twice to get result of the following math expression.
math expression =(CURR[1]-CURR[0])

Parameters

Input
Name Type Description
instrumentHandle ViSession The ViSession handle that you obtain from the agb2900_Initialize function.  The handle identifies a particular instrument session that can be passed to other functions.
Default Value:  None
channel ViInt32 Specified channel to perform action.
Valid Values:
AGB2900_INSTRUMENT_CHANNEL_1: Channel 1 (B2901BL, B2910BL, B2901B, B2911B, B2961B)
AGB2900_INSTRUMENT_CHANNEL_2: Channel 2 (B2902B, B2912B, B2962B)
Default Value:
AGB2900_INSTRUMENT_CHANNEL_1: Channel 1
Output
Name Type Description
calculationData ViReal64 (passed by reference) Calculation Result.
timeStamp ViReal64 (passed by reference) Time stamp of calculation data.
status ViReal64 (passed by reference) Status data is given by a binary-weighted sum of all bits set in the binary data.
<b>Bit Definitions of Status Data</b>
bit 0 - Source (0: Voltage; 1: Current)
bit 1 and 2 - Compliance condition(0: No; 1, 2, 3: Yes)
bit 3 - Over voltage condition(0: No; 1: Yes)
bit 4 - Over current condition(0: No; 1: Yes)
bit 5 - High temperature condition(0: No; 1: Yes)
bit 13 - Measurement range overflow(0: No; 1: Yes)
bit 14 - Offset compensation enable condition(0: No; 1: Yes)
bit 15 - Contact check failure(0: No; 1: Yes)
bit 16 to 20 - Limit test result, 0 to 31

Return Value

Name Type Description
status ViStatus Returns the status code of this operation.  The status code indicates success or describes an error or warning condition. You can examine the status code from each call to an instrument driver function to determine whether an error occurred.
To obtain a description of the last error, call the agb2900_ErrorMessage function.
In general, you can interpret status codes as follows:
Value                  Meaning
-------------------------------
0                      Success
Positive Values        Warnings
Negative Values        Errors
This driver defines the following status codes:
Status    Description
-------------------------------------------------
No defined status codes.
This instrument driver also returns errors and warnings defined by other sources.  The following table defines additional status code ranges that this driver can return.
Numeric Range (in Hex)   Status Code Types    
-------------------------------------------------
3FFF0000 to 3FFFFFFF     VISA     Warnings
3FFC0000 to 3FFCFFFF     VXIPnP   Driver Warnings
BFFF0000 to BFFFFFFF     VISA     Errors
BFFC0000 to BFFCFFFF     VXIPnP   Driver Errors

agb2900_ConfigureOutputTrigger

ViStatus agb2900_ConfigureOutputTrigger (ViSession instrumentHandle, ViInt32 channel, ViInt32 deviceAction, ViInt32 triggerSignal, ViBoolean triggerEnabled, ViInt32 triggerLocation, ViInt32 triggerTiming);

Purpose

Configure output triggers for status change between idle-arm, arm-trigger or trigger-action layer.

Parameters

Input
Name Type Description
instrumentHandle ViSession The ViSession handle that you obtain from the agb2900_Initialize function.  The handle identifies a particular instrument session that can be passed to other functions.
Default Value:  None
channel ViInt32 Specified channel to perform action.
Valid Values:
AGB2900_INSTRUMENT_CHANNEL_1: Channel 1 (B2901BL, B2910BL, B2901B, B2911B, B2961B)
AGB2900_INSTRUMENT_CHANNEL_2: Channel 2 (B2902B, B2912B, B2962B)
Default Value:
AGB2900_INSTRUMENT_CHANNEL_1: Channel 1
deviceAction ViInt32 Specified device action for trigger configuration. Only effective for status change between arm-trigger and idle-arm layers.
Valid Values:
AGB2900_DEVICE_ACTION_ACQUIRE: Acquire. Measurement action.
AGB2900_DEVICE_ACTION_TRANSIENT: Transient. Source output action.
AGB2900_DEVICE_ACTION_BOTH: Both. Both device action.
Default Value:
AGB2900_DEVICE_ACTION_BOTH: Both
Note:
This value is only effective when Trigger Location is set to Idle-ARM or ARM-Trigger
triggerSignal ViInt32 The output trigger for the status change between specified layers (controlled by Trigger Signal value). Multiple output triggers can be set.
Valid Values:
AGB2900_TRIGGER_SIGNAL_EXT1: EXT1. selects a signal from the GPIO pin n which is an output port of the Digital I/O D-sub connector on the rear panel.
AGB2900_TRIGGER_SIGNAL_EXT2: EXT2.
AGB2900_TRIGGER_SIGNAL_EXT3: EXT3.
AGB2900_TRIGGER_SIGNAL_EXT4: EXT4.
AGB2900_TRIGGER_SIGNAL_EXT5: EXT5.
AGB2900_TRIGGER_SIGNAL_EXT6: EXT6.
AGB2900_TRIGGER_SIGNAL_EXT7: EXT7.
AGB2900_TRIGGER_SIGNAL_EXT8: EXT8.
AGB2900_TRIGGER_SIGNAL_EXT9: EXT9.
AGB2900_TRIGGER_SIGNAL_EXT10: EXT10.
AGB2900_TRIGGER_SIGNAL_EXT11: EXT11.
AGB2900_TRIGGER_SIGNAL_EXT12: EXT12.
AGB2900_TRIGGER_SIGNAL_EXT13: EXT13.
AGB2900_TRIGGER_SIGNAL_EXT14: EXT14.
AGB2900_TRIGGER_SIGNAL_LAN: LAN. Selects LXI triggers specified by LXI Triggers Control.
AGB2900_TRIGGER_SIGNAL_INT1: INT1. Selects the output of the channel 1 or 2 respectively. Available only for the 2-channel model.
AGB2900_TRIGGER_SIGNAL_INT2: INT2.
Default Value:
AGB2900_TRIGGER_SIGNAL_EXT1: EXT1
triggerEnabled ViBoolean Expected status of the trigger output for the status change between the idle state and the arm layer.
Valid Range:
VI_TRUE - Enabled
VI_FALSE - Disabled
Default Value:
VI_FALSE
triggerLocation ViInt32 Specify between which two layer is the output trigger used to change status.  
Valid Values:
AGB2900_TRIGGER_LOCATION_IDLE_ARM: Idle-ARM.  Change status between the idle state and the arm layer.
AGB2900_TRIGGER_LOCATION_ARM_TRIGGER: ARM-Trigger. Change status between the arm layer and the trigger layer..
AGB2900_TRIGGER_LOCATION_TRIGGER_ACQUIRE: Trigger-Acquire: Change status between the trigger layer and acquire device action.
AGB2900_TRIGGER_LOCATION_TRIGGER_TRANSIENT: Trigger-Transient: Change status between the trigger layer and the transient device action.
Default Value:
AGB2900_TRIGGER_LOCATION_IDLE_ARM Idle-ARM
triggerTiming ViInt32 Specified output trigger timing of the specified channel.
Valid Values:
AGB2900_TRIGGER_TIMING_BEFORE: Before. Enables the trigger output at the beginning of arm, trigger, and device action (transient or acquire).
AGB2900_TRIGGER_TIMING_AFTER: After. Enables the trigger output at the end of arm, trigger, and device action (transient or acquire).
AGB2900_TRIGGER_TIMING_BOTH: Both. Enables the trigger output at both the beginning and the end of arm, trigger, and device action (transient or acquire).
Default Value:
AGB2900_TRIGGER_TIMING_BOTH: Both

Return Value

Name Type Description
status ViStatus Returns the status code of this operation.  The status code indicates success or describes an error or warning condition. You can examine the status code from each call to an instrument driver function to determine whether an error occurred.
To obtain a description of the last error, call the agb2900_ErrorMessage function.

agb2900_ReadIndividualLimitTestResult

ViStatus agb2900_ReadIndividualLimitTestResult (ViSession instrumentHandle, ViInt32 channel, ViInt32 testNumber, ViPBoolean testFailed);

Purpose

Read the individual test result by specified test number.
Note:
(1) Use this method only with other low-level methods. The high-level methods automatically incorporate this functionality.
(2) This function is not applicable for B296x family models B2961A/B2962A, B2961B/B2962B, and B2961C/B2962C.

Parameters

Input
Name Type Description
instrumentHandle ViSession The ViSession handle that you obtain from the agb2900_Initialize function.  The handle identifies a particular instrument session that can be passed to other functions.
Default Value:  None
channel ViInt32 Specified channel to perform action.
Valid Values:
AGB2900_INSTRUMENT_CHANNEL_1: Channel 1 (B2901BL, B2910BL, B2901B, B2911B, B2961B)
AGB2900_INSTRUMENT_CHANNEL_2: Channel 2 (B2902B, B2912B, B2962B)
AGB2900_INSTRUMENT_CHANNEL_BOTH: Both(B2912A, B2902A, B2901B/B2902B, B2911B/B2912B, B2961B/B2962B)
Default Value:
AGB2900_INSTRUMENT_CHANNEL_1: Channel 1
testNumber ViInt32 An integer used to specify a limit test to apply configuration.
Valid Range:
1 to 12
Default Value:
1
Output
Name Type Description
testFailed ViBoolean (passed by reference) A boolean value indicates the results of specified limit test
True - Failed
False - Passed

Return Value

Name Type Description

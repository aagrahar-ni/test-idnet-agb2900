agb2900_ConfigureMathExpression

ViStatus agb2900_ConfigureMathExpression (ViSession instrumentHandle, ViInt32 channel, ViBoolean expressionEnabled, ViChar _VI_FAR expressionName[], ViChar _VI_FAR expressionDefinition[], ViChar _VI_FAR expressionUnitName[]);

Purpose

Configures the math expression for the Limit Test Calculation.

Parameters

Input
Name Type Description
instrumentHandle ViSession The ViSession handle that you obtain from the agb2900_Initialize function.  The handle identifies a particular instrument session that can be passed to other functions.
Default Value:  None
channel ViInt32 Specified channel to perform action.
Valid Values:
AGB2900_INSTRUMENT_CHANNEL_1: Channel 1 (B2901BL, B2910BL, B2901B, B2911B, B2961B)
AGB2900_INSTRUMENT_CHANNEL_2: Channel 2 (B2902B, B2912B, B2962B)
Default Value:
AGB2900_INSTRUMENT_CHANNEL_1: Channel 1
expressionEnabled ViBoolean Enables or disables the math expression.
Valid Range:
VI_TRUE  - Enable
VI_FALSE - Disable
Default Value: VI_FALSE
expressionName ViChar[] The name of math expression to apply definition. If the name does not exist, a new expression is created.
Valid Values:
Up to 32 ASCII characters.
Default Value:
"MyMath1"
expressionDefinition ViChar[] An user-defined math expression.
Valid Range:
Up to 256 ASCII characters.
The following resources can be used in the user-defined math expressions:
Reserved variables([c]specifies the channel):
SOUR[c], SOUR[c][]
VOLT[c], VOLT[c][]
CURR[c], CURR[c][]
RES[c], RES[c][]
TIME[c], TIME[c][]
Math Operation:
+, -, *, /, ^, ( )
Ln, log, sin, cos, tan, exp
Default Value:
"(VOLT*CURR)"
expressionUnitName ViChar[] Defines the unit name for the math expression. Up to 32 ASCII characters.
Default Value:
"W"

Return Value

Name Type Description
status ViStatus Returns the status code of this operation.  The status code indicates success or describes an error or warning condition. You can examine the status code from each call to an instrument driver function to determine whether an error occurred.
To obtain a description of the last error, call the agb2900_ErrorMessage function.

Value                  Meaning

Positive Values        Warnings
Negative Values        Errors

agb2900_ConfigureListSweep

ViStatus agb2900_ConfigureListSweep (ViSession instrumentHandle, ViInt32 channel, ViInt32 outputMode, ViBoolean listSweepEnabled, ViReal64 _VI_FAR listData[], ViInt32 dataLength, ViInt32 listDataMode, ViInt32 startIndex);

Purpose

Change settings for sweep list.
The list sweep function is effective for performing an arbitrary waveform output. The SMU can apply the waveform and measure voltage or current at each output value.

Parameters

Input
Name Type Description
instrumentHandle ViSession The ViSession handle that you obtain from the agb2900_Initialize function.  The handle identifies a particular instrument session that can be passed to other functions.
Default Value:  None
channel ViInt32 Specified channel to perform action.
Valid Values:
AGB2900_INSTRUMENT_CHANNEL_1: Channel 1 (B2901BL, B2910BL, B2901B, B2911B, B2961B)
AGB2900_INSTRUMENT_CHANNEL_2: Channel 2 (B2902B, B2912B, B2962B)
Default Value:
AGB2900_INSTRUMENT_CHANNEL_1: Channel 1
outputMode ViInt32 Specified list sweep mode to apply settings.
Valid Values:
AGB2900_SOURCE_OUTPUT_MODE_CURRENT: Current List Sweep
AGB2900_SOURCE_OUTPUT_MODE_VOLTAGE: Voltage List Sweep
Default Value:
AGB2900_SOURCE_OUTPUT_MODE_VOLTAGE: Voltage
listSweepEnabled ViBoolean Expected status of list sweep function.
Valid Range:
VI_TRUE:  Enable. Output source is set to list sweep.
VI_FALSE: Disable. Output source is set to constant current or voltage source.
Default Value:
VI_FALSE: Disable
listData ViReal64[] List of the output current or voltage data.
An array contains current or voltage levels to be output.
Valid Range:
Maximum 1001 data can be set.
For valid range of each element which indicates a current or voltage value, see help context for Output Level control in Configure Source.vi.
Default Value:
0
dataLength ViInt32 The length of list data array.
Valid Range:
>=0
Default value: 0
listDataMode ViInt32 The mode to apply list data.
Valid Values:
AGB2900_SWEEP_LIST_DATA_MODE_APPEND: Append. Append the list data to existing list.
AGB2900_SWEEP_LIST_DATA_MODE_NEW: New List. Delete old list, use specified list data as  fresh new list.
Default Value:
AGB2900_SWEEP_LIST_DATA_MODE_NEW: New List
startIndex ViInt32 Specifies the list sweep start point by using the index of the list. Index 0 and 1 indicate the first data in the list (top of the list).
Valid Range:
Index of the list. 0 to the number of data in the list.
Default Value: 0

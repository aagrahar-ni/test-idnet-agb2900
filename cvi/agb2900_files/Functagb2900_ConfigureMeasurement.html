agb2900_ConfigureMeasurement

ViStatus agb2900_ConfigureMeasurement (ViSession instrumentHandle, ViInt32 channel, ViInt32 measurementMode, ViReal64 range, ViBoolean automaticNPLCEnabled, ViReal64 powerLineCycle, ViInt32 resistanceMode, ViBoolean resistanceCompensatedEnabled);

Purpose

Configures the specified measurement.
Note:
Commands in the outer conditional statement are not applicable for B296x family models B2961A/B2962A, B2961B/B2962B, and B2961C/B2962C.   

Parameters

Input
Name Type Description
instrumentHandle ViSession The ViSession handle that you obtain from the agb2900_Initialize function. The handle identifies a particular instrument session that can be passed to other functions.
Default Value:  None

Valid Values:
AGB2900_INSTRUMENT_CHANNEL_1: Channel 1 (B2901BL, B2910BL, B2901B, B2911B, B2961B)
AGB2900_INSTRUMENT_CHANNEL_2: Channel 2 (B2902B, B2912B, B2962B)
Default Value:
AGB2900_INSTRUMENT_CHANNEL_1: Channel 1

Valid Values:
AGB2900_MEASUREMENT_MODE_VOLTAGE: Voltage measurement
AGB2900_MEASUREMENT_MODE_CURRENT: Current measurement
AGB2900_MEASUREMENT_MODE_RESISTANCE: Resistance measurement

AGB2900_MEASUREMENT_MODE_VOLTAGE: Voltage

Default Value: VI_FALSE
powerLineCycle ViReal64 The number of power line cycles (NPLC) value which indicates the measurement speed. The NPLC value can be expressed by the following formula by using the integration time:
nplc = time * power line frequency
Valid Range:
4E-4 to   100 for 50Hz
4.8E-4 to 120 for 60Hz
Default Value:
0.1 PLC
Notes:
This parameter is ignored if the Automatic NPLC Enabled.
resistanceMode ViInt32 Selects the resistance measurement mode.
Valid Values:
AGB2900_MEASUREMENT_RESISTANCE_MODE_MANUAL: Manual is selected, the source and measurement condition must be set manually. If the resistance measurement                        function is enabled, the resistance is calculated by voltage/current. The resistance measurement range cannot be set.
AGB2900_MEASUREMENT_RESISTANCE_MODE_AUTO:   AUTO is selected, the channel automatically sets the current source and voltage measurement if the resistance                             measurement function is enabled. The current output value and range depend on the resistance measurement range                selected by the :SENS:RES:RANG:UPP or SENS:RES:RANG:AUTO:LLIM and :SENS:RES:RANG:AUTO:ULIM commands. And the following parameters are set automatically.
Default value:
AGB2900_MEASUREMENT_RESISTANCE_MODE_MANUAL: Manual
Note:
This parameter value is only available for the resistance measurement.
resistanceCompensatedEnabled ViBoolean Enables or disables the offset-compensated resistance measurement. This parameter value is only available for the resistance measurement.
Valid Range:
VI_TRUE  - Enable
VI_FALSE - Disable
Default Value: VI_FALSE

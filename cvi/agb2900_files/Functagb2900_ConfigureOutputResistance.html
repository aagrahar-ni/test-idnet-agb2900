agb2900_ConfigureOutputResistance

ViStatus agb2900_ConfigureOutputResistance (ViSession instrumentHandle, ViInt32 channel, ViInt32 outputMode, ViInt32 operationMode, ViConstString _VI_FAR listOfSourceType[], ViInt32 listOfSourceTypeSize, ViInt32 listOfOutputDataSize, ViReal64 _VI_FAR listOfOutputData[], ViReal64 shuntResistanceLevel, ViReal64 seriesResistanceLevel, ViBoolean enableProgrammableOutput);

Purpose

Configures the output resistance.
Note:
This function is only supported by B296x family models B2961A/B2962A, B2961B/B2962B, and B2961C/B2962C.

Parameters

Input
Name Type Description
instrumentHandle ViSession The ViSession handle that you obtain from the agb2900_Initialize function.  The handle identifies a particular instrument session that can be passed to other functions.
Default Value:  None
channel ViInt32 Specified channel to perform action.
Valid Values:
AGB2900_INSTRUMENT_CHANNEL_1: Channel 1 (B2901BL, B2910BL, B2901B, B2911B, B2961B)
AGB2900_INSTRUMENT_CHANNEL_2: Channel 2 (B2902B, B2912B, B2962B)
Default Value:
AGB2900_INSTRUMENT_CHANNEL_1: Channel 1
outputMode ViInt32 Sets the source output mode of the specified channel.
Valid Values:
AGB2900_SOURCE_OUTPUT_MODE_CURRENT: Current. Sets the specified channel to the current source.
AGB2900_SOURCE_OUTPUT_MODE_VOLTAGE: Voltage. Sets the specified channel to the voltage source.
Default Value:
AGB2900_SOURCE_OUTPUT_MODE_VOLTAGE: Voltage
operationMode ViInt32 Selects the operation mode of the programmable output resistance function.
Valid Values:
AGB2900_RESISTANCE_OPERATION_MODE_FIXED: Fixed. The fixed mode which uses the constant output resistance.
AGB2900_RESISTANCE_OPERATION_MODE_EMULATE: Emulate. The emulation mode which uses the user-specified voltage and current lists.
Default Value:
AGB2900_RESISTANCE_OPERATION_MODE_FIXED: Fixed
listOfSourceType ViConstString[] Sets the source type list used for the emulation mode operation of the programmable output resistance function.
Valid Range:
List must contain 1 to 15 data. Each data must be separated by a comma, for example: list=VOLT,VOLT.
Default Value:
VI_NULL
listOfSourceTypeSize ViInt32 Sets the size of source type list.
Valid Range:
1 to 15
Default Value:
1
listOfOutputDataSize ViInt32 Sets the size of output data list.
Valid Range:
2 to 16
Default Value:
2
listOfOutputData ViReal64[] Sets the current or voltage list used for performing the emulation mode operation of the programmable output resistance function.
Valid Range:
List must contain 2 to 16 data. Number of data must be the number of data in the source type list plus 1. Each data must be separated by a comma, for example: list=0.1,0.2,0.3.
Default Value:
VI_NULL
shuntResistanceLevel ViReal64 Sets the shunt resistance (constant value) used for the fixed mode operation of the programmable output resistance function.
Valid Range:
0.2 Ohm to 2G Ohm
Default Value:
2000000000 Ohm
seriesResistanceLevel ViReal64 Sets the series resistance (constant value) used for the fixed mode operation of the programmable output resistance function.
Valid Range:
-20M to +20M Ohm
Default Value:
0 Ohm
enableProgrammableOutput ViBoolean Enables or disables the programmable output resistance function.
Valid Values:
VI_TRUE:  Enable. Enables the trigger output.
VI_FALSE: Disable. Disables the trigger output.
Default Value:
VI_FALSE: Disable
